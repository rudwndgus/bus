# 시각 비교 및 검증 결과

기준 녹화: 592×1280, 50.52초. FFmpeg 7.1로 3초 간격 17장, 2fps 101장, scene 변화 임계값 0.12로 50장, 주요 시점 원본 해상도 프레임을 추출했다. `scene-times.json`은 자동 감지 시간표이며, 안정된 장면은 contact sheet를 보고 별도 선택했다. 영상·원본 프레임·원본을 포함하는 비교 이미지는 로컬에만 보관한다.

## 반복 비교

1. 최초 592×1280 구현 캡처를 원본 home(4s), rider(5.5s), buy(19s), fares(14s), confirmation(21.5s)와 대조했다.
2. 홈의 뉴스·구매 카드가 3–9px 아래로 밀리는 현상을 줄였다. 운임 화면에는 하단 탭이 없음을 반영했고, purchase 헤더를 155px로 조정했다. 운임 하단 버튼은 y=1117에 맞췄다. 경로 필드 x=147, 오른쪽=518, 운임 행 왼쪽=24를 반영했다.
3. 원본 색상을 직접 샘플링해 헤더 #00448d, 합계 배경 #f47736, 구매 행 #f0eff5를 반영했다. 확인 모달 수직 위치를 조정했다.
4. 캡처 시 이전 React 화면 또는 애니메이션 중간 상태가 저장되는 문제를 발견해 화면 제목 대기와 reduced-motion을 적용했다. 최종 캡처는 `implementation/`에 있다.

## 결과와 남는 차이

- 홈 뉴스 카드 x=24, y≈495 (원본 y≈496), 하단 탐색 시작 y=1150으로 맞췄다.
- 운임 화면의 헤더/경로/합계 경계 y≈155/339/413 (원본 155/339/414), checkout y=1117과 폭544를 맞췄다.
- My Tickets segmented control과 섹션 바 위치를 원본에 맞췄다. 상태가 바뀌면 원본처럼 섹션이 추가된다.
- SF 폰트 원본 파일이 없어 Arial/system 계열로 대체한다. 글자 폭과 굵기, 일부 텍스트 기준선에 차이가 있다.
- 직접 그린 열차/교량 SVG, Lucide 아이콘, 일반화한 노선 엠블럼은 원본 그림과 다르다.
- 티켓 화면은 인증 그림·QR·인증 애니메이션·유효시간 카운트다운을 제거한 비승차 미리보기다. 이를 시각 오차로 숨기지 않는다.
- 전체 화면 픽셀 일치율은 계산하지 않았다. 이미지·글꼴·보안 관련 의도적 차이가 커서 단일 점수는 오해를 만든다. pixel-perfect라는 주장은 하지 않는다.

## 자동 검증

- TypeScript / production build
- ESLint
- Vitest 5개: 운임 합계, 수량 하한, checkout 미확인 안내, 미리보기 저장, 테마 저장, 즐겨찾기 상태 토글(일부 항목은 같은 테스트)
- Playwright 10개: 3개 탭, 구매/수량/뒤로, 취소/미리보기/확대/안내/히스토리/로컬 새로고침, 미확인 동작과 잘못된 경로, 320/393/1440px 뷰포트, 참조용 캡처, CSS 테마 재로딩, production PWA offline revisit
- 실제 iPhone Safari/Android Chrome 기기 검증은 하지 않았다. Chromium에서 반응형과 오프라인을 검증했다.

## 배포 변경

사용자가 Vercel 대신 GitHub Pages를 선택하고, 현재 계정의 private Pages 미지원(HTTP422)을 확인한 후 `bus` 저장소를 공개로 변경해 무료 Pages에 배포하도록 명시적으로 승인했다. `/bus/` asset base와 HashRouter, scope를 따르는 서비스 워커를 사용한다. 원본 비공개 요구는 이 후속 승인으로 변경됐다.

- Pages 전용 Playwright 2개 추가 통과: `/bus/` 자산 경로, HashRouter 새로고침, scope 및 오프라인 재방문.
