## 재현 제한과 미확인 동작

- 햄버거 메뉴 내용, 알림 메뉴, 목적지 검색 결과, 홈 하단 Favorites 내용, 교통수단별 다음 화면, 경로/존 선택 옵션, checkout/결제 화면, 환불 절차, 계정/설정 화면은 열리지 않았다. 해당 제어는 원본 레이아웃으로 유지하되 클릭 시 확인 불가 안내만 제공. 검증되지 않은 화면을 원본처럼 만들어내지 않는다.
- 운임은 Quick Buy의 첫 항목(1 - Newark / Zone 3)에서 보인 여섯 행만 검증. 아래에서 잘린 다음 운임은 값/명칭 불명이라 추가하지 않는다.
- 나머지 Quick Buy 항목은 보인 텍스트만 재현하며 운임을 추측하지 않는다.
- 녹화 속 QR과 승차권 인증 패턴은 별도 자산으로 분리하거나 배포하지 않는다. 전체 참조 프레임은 로컬 분석에만 보관한다. 시간 기반 보안 색상과 작동하는 티켓/인증정보는 생성하지 않는다. 미리보기는 NOT VALID FOR TRAVEL 표시, QR 대신 텍스트 패널, 임의의 개발 색상 사용. 실제 활성화/구매/결제 없음.
- Validator Instructions 그림의 세부 자산은 재사용 권리가 확인되지 않아 직접 그린 간단한 설명 그림으로 대체. 이 화면은 안전한 미리보기임을 안내.
- 아이콘은 Lucide와 자체 SVG 사용. 원본 노선 엠블럼과 완전히 같지는 않음.
- 홈 배경과 공지 이미지의 독립적 재배포 라이선스가 확인되지 않아 공개 빌드에서는 직접 그린 대체 이미지 사용. 원본 프레임과 원본을 포함한 비교 이미지는 로컬에만 보관.
- 공식 데이터: https://www.njtransit.com/app / https://developer.njtransit.com/registration/loginsein . 개발자 포털은 인증/등록 기반. 계정·API 키 없으므로 실시간 연동하지 않음. fixture 서비스와 API 경계 분리.
